# Packaged license omissions

`@vue/devtools-api@6.6.4` declares MIT but omits its license file from the published package.
`vue-devtools-api-6.6.4.txt` is the unmodified [license at upstream tag v6.6.4](https://github.com/vuejs/vue-devtools/blob/v6.6.4/LICENSE).
The notice generator uses this copy only for that exact package and version when no packaged license exists.
Other missing licenses remain build errors. Review this exception when updating Vue I18n.
