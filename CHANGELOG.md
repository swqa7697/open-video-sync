## [Unreleased]

### Added

- Add browser-local Bilibili AVC/AAC playback and danmaku through an instance-scoped Tampermonkey helper. Each participant uses their own platform access. Support exact multipart matching, room controls and waiting, bounded streaming with local expiry refresh, and local comment visibility, density, and text size. Helper failures show grouped next steps. A participant without platform access stays unready and appears to others as Platform access unavailable.
- Add local synchronized viewing with browser-only file selection, sampled media matching over HTTP, authenticated room controls, automatic playback takeover between pages, clock calibration, drift correction, and reconnect. On a high-latency link, the page states that synchronization may drift, and waits and room controls stay available. Support startup and buffering waits that name the participants being waited for, ready late-join catch-up, and controller permission during host absence, with the reason when room controls are unavailable. Cancelling a play attempt keeps media usable without a playback error. When Enable playback disappears, keyboard focus stays in the player. Playback restarts paused at zero; persistent-write failures leave existing playback available.
- Add persistent anonymous identities and private rooms with reusable invitation links/codes, host/everyone controls and wait-for-everyone preferences, member removal, leave, closure, immediate session revocation, and bounded expired-session cleanup. Support direct HTTP with session/CSRF protection and isolated browser profiles. Keyboard operation keeps focus on the current task, status text is readable, server status distinguishes unreachable from unable to save, and room endings, connection, storage, and session failures each give their own recovery step.
- Add an embedded Vue interface with a muted Slate blue default and selectable Soft iris and Graphite accents. Light and dark modes follow the system by default, with browser-local overrides that survive reloads. Dialog transitions and subtle button feedback respect reduced motion and keep keyboard actions immediate. Include HTTP health checks, validated configuration, and SQLite migrations with exclusive data-directory ownership.
- Add development, validation, and release commands, plus a non-root application container with persistent `/data` storage. Combine the sync, web, and helper versions in local image tags. Deploy and manage remote Linux servers over SSH with Docker, automatic Compose preparation, and optional Caddy HTTPS for public IPs or domains. Preserve data across updates and verify public HTTPS without accepting untrusted certificates. Keep manual and existing-proxy deployment support. Optional trusted-proxy CIDRs keep per-client request limits behind a reverse proxy.
